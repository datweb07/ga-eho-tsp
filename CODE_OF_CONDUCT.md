# Code of Conduct

## Our expectations

Everyone participating in this project should treat others with respect. Give constructive feedback, discuss technical disagreements using evidence, credit other people's work, and help teammates understand the implementation.

Harassment, discriminatory remarks, threats, personal attacks, sharing private information without consent, and deliberate misrepresentation of contributions or experimental results are unacceptable.

## Scope

These expectations apply to issues, pull requests, code reviews, project discussions, and other spaces where participants represent this project.

## Reporting and response

Report concerns privately to the project lead, Trương Thành Đạt, through an existing private team contact. Do not publish another person's private information in an issue.

The project lead should review reports confidentially, hear the people involved, and respond proportionately. Responses may include a request to correct behavior, removal of inappropriate content, or restrictions on participation. A report involving the project lead should be brought to another team member or the course supervisor through an existing private contact.
